# Assay Design domain calibration

Eight UI domains exercise corrected controls and one isolated mutant for every AVP design criterion.

| Measurement | Result |
| --- | ---: |
| Domains | 8 |
| Corrected controls | 8 |
| Mutants detected | 40/40 |
| Missed mutants | 0 |
| False alarms | 0 |
| Overall | PASS |

Domains: analytics, commerce, healthcare, fintech, government, media, education, travel.

## Limits

- Fixtures are deterministic and synthetic.
- This measures declared design-system conformance, not subjective beauty or usability.
- Browser geometry, assistive technology, and model/human judgment remain AVP concerns outside this static benchmark.
